# glossário

Formato: `termo | outro termo => como deve ficar`. Troca palavra inteira, sem diferenciar maiúscula.

news | new => newsletter
nova ativa | inovativa => Inovativa
bnds | brds | bndes => BNDES
alanding => a landing
quitandinho | s quitandinha => Quitandinha
