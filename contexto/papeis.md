# papéis das sócias

Quem costuma fazer o quê. É sugestão, não regra dura: no dia a dia cada uma adapta a tarefa à sua vontade.
Usar só quando a fala não diz quem faz.

- juliana: gestão, tarefas, reunião, marcar horários e encontros, revisão de texto
- larissa: design
- viviane: desenvolvimento
- pesquisa: as três podem fazer

Atenção: dono é quem faz a ação, não de quem é o assunto. "marcar a conversa sobre o design system com a Lari" é da Juliana; quem explica é a Lari.
Enquanto a transcrição não separar as vozes, o "eu" é desconhecido. Nunca atribuir o "eu" a uma pessoa só.
